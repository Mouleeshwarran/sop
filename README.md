1. Install Python 3.12.x
2. Install Git
3. Install VS Code
4. Clone the GitHub repository
5. Open the project in VS Code
6. Run:
   py -3.12 -m venv .venv

7. Activate:
   .\.venv\Scripts\Activate.ps1

8. Install:
   pip install ultralytics opencv-python numpy matplotlib pandas pyyaml

9. Verify:
   python --version
   yolo version

10. Get the shared:
    best.pt
    dataset
    testing videos/images

11. Run the project
